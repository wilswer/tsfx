calculate_sequential_ols 🔒
Ordinary least squares intercept and slope of y against its index $0, 1, \dots, n - 1$, as scipy.stats.linregress (which tsfresh uses) computes them: centred sums, $b = \sum (i - \bar{i})(y_i - \bar{y}) / \sum (i - \bar{i})^2$ and $a = \bar{y} - b,\bar{i}$, summed as numpy does. (A one-pass $\sum i,y_i - n,\bar{i},\bar{y}$ loses digits to cancellation.) NaN for fewer than 2 values.

numpy_linspace 🔒
num evenly spaced values from start to stop (both included), exactly as np.linspace(start, stop, num) computes them: $i \cdot s + \text{start}$ with step $s = (\text{stop} - \text{start}) / (\text{num} - 1)$ (or $(i / (\text{num} - 1)) \cdot \Delta + \text{start}$ if the step underflows to 0), the last value set to stop.
numpy_mean

numpy_median
The median of values (not empty, reordered in place), exactly as np.median computes it: the np.mean of the middle value, or of the two middle values for an even count. Found with a selection, $O(n)$.
numpy_quantile
The q-quantile of sorted (ascending, not empty), exactly as np.quantile computes it (method “linear”): index $h = (n - 1),q$, neighbours $a = x_{(\lfloor h \rfloor)}$, $b = x_{(\lfloor h \rfloor + 1)}$ and weight $t = h - \lfloor h \rfloor$, then numpy’s _lerp: $a + (b - a),t$ for $t < 0.5$, $b - (b - a)(1 - t)$ otherwise. At or beyond the last index numpy uses the last value for both neighbours with $t = h + 1$ (it computes the weight from the replacement index $-1$). So an infinite neighbour can give NaN, exactly as in numpy.
numpy_searchsorted_left 🔒
np.searchsorted(arr, keys, side="left"), reproducing numpy’s binary search step for step (including how it reuses the bounds of the previous key), so that the result also equals numpy’s when arr is not sorted (for example edges that came out NaN).
numpy_sum
Sum of value(0), ..., value(n - 1) exactly as numpy’s add.reduce sums a contiguous float64 array (numpy 2.x): pairwise summation with eight accumulators for blocks of up to 128 values, split in halves above that, added to an initial 0.0. Results equal numpy’s bit for bit, which a straight or Welford sum does not.
