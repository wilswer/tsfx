Function pandas_moments

fn pandas_moments(x: &[f64], skipna: bool) -> (usize, [f64; 3])
Expand description

The number of non-NaN values of x and its central moment sums $m_k = \sum_i (x_i - \mu)^k$ for $k = 2, 3, 4$, bit for bit as pandas 3.1 computes them for Series.skew and Series.kurtosis (moments_reduce, x86_64 build).

pandas sums in two passes: a trial mean, then the powers of the deviations from it, both in two SSE2 lanes with pairwise sums (see pandas_mean_lanes) and the odd last value added on its own. The trial mean’s rounding error is then corrected (Pébay et al., 2016), so a constant series gives exactly $m_2 = 0$. With skipna, NaN values are skipped where they are; without it, a NaN makes every sum NaN.
