pub fn load_config(file_path: Option<&str>) -> Result<Config, ConfigError>
Expand description

Load the feature config from file_path, or without one from DEFAULT_CONFIG_FILE in the working directory. Without a file_path, a missing DEFAULT_CONFIG_FILE gives the default config; a given file_path must exist (ConfigError::Read otherwise), so a mistyped path is not silently replaced by the defaults.
