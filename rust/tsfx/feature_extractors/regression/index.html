Constants§

GRAM_BLOCK_ROWS 🔒
Rows per block when accumulating the Gram matrix, so that a block of every column stays in cache.
IC_TIE_TOL 🔒
Information criteria closer than this (relative to their magnitude, at least 1) count as equal when choosing the ADF lag.
MAX_GRAM_CONDITION 🔒
Fits whose column-scaled design has a condition number bound below this are solved from the Gram matrix (see Ols::fit_prefixes_gram).
MAX_GRAM_RESIDUAL_ERROR 🔒
The largest estimated relative error of a residual sum of squares the Gram matrix path accepts. That residual is computed as a difference, $y^T y - \lVert c \rVert^2$, whose rounding error is about $\varepsilon,\kappa^2,y^T y$ for a (scaled) condition number $\kappa$; t-values and information criteria magnify it when few degrees of freedom remain.
PERFECT_FIT_TOL 🔒
Residuals at most this fraction of the scale of the fitted terms count as an exact fit (see Ols::fit).

Householder QR decomposition $X = QR$ of the matrix with columns x (at least as many rows as columns). Returns the columns of the upper triangular $R$ (each of length $k$) and $Q^T y$.
jacobi_svd 🔒
One-sided Jacobi (Hestenes) SVD of the matrix with columns a: rotate pairs of columns until all are orthogonal, applying the same rotations to the identity. Returns the rotated columns $U_j = s_j u_j$ (not normalised), the singular values $s_j = \lVert U_j \rVert$ (unsorted) and the right singular vectors $v_j$ as columns, so that $A = \sum_j U_j v_j^T$.
