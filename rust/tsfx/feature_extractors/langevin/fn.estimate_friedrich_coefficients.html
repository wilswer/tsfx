fn estimate_friedrich_coefficients(
    x: &[f64],
    m: usize,
    r: usize,
) -> Option<Vec<f64>>
Expand description

Coefficients of the polynomial $h$ of degree m (highest power first, as np.polyfit) fitted to the deterministic dynamics $\dot{x}(t) = h(x(t)) + \mathcal{N}(0, R)$ of a Langevin model (Friedrich et al., 2000), exactly as tsfresh’s _estimate_friedrich_coefficients computes them:

  1. pair each value $x_t$ (all but the last) with the change $x_{t+1} - x_t$;
  2. bin the values into r quantile bins, as pd.qcut(x[:-1], r);
  3. average values and changes per bin, as pandas’ group-by mean;
  4. fit the polynomial through the bin averages by least squares, as np.polyfit(..., deg=m).

None where tsfresh returns NaN coefficients: duplicate quantile bin edges (pd.qcut raises), or a fit that fails (np.linalg.lstsq raises on non-finite input). Also None (tsfresh raises instead) for fewer than 2 values, m = 0, r = 0, or when every bin average is NaN.
