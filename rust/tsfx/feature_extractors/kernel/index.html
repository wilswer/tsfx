Module kernel

Expand description

All features of a value column computed in one pass over each group.

Polars collects a group’s values into a list once per apply, and with dozens of features that dominated extraction time. Instead, one apply per value column builds a GroupContext (the group’s values plus statistics that several features share, each computed at most once) and runs every Kernel on it, returning all of the group’s features as one list. After the group-by, KernelPlan::unpack turns list position i into the named feature column i.
