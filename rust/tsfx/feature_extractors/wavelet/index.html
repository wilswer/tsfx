Module wavelet 

Source
Expand description

Continuous wavelet transforms with the Ricker (“Mexican hat”) wavelet.

Both features convolve the series with sampled wavelets, using one portable direct convolution, so results are the same on every platform. They equal tsfresh’s within rounding. NumberCwtPeaks compares neighbouring coefficients; where two are tied in real arithmetic (for example on a series symmetric about a point between two samples), rounding decides, and the count can differ from tsfresh’s. numpy’s own result there depends on its BLAS and CPU.
