Module reduction 

Source
Expand description

Reduction of the extracted features before scaling: drop features that are mostly missing, almost always one value, near-duplicates of an earlier feature, or noise (no better than shuffled “shadow” features at respecting the neighbor structure of the rows); then, with a cap, keep only the most informative of the rest (greedy column subset selection).

The steps decide which columns remain; the values of the columns kept are not changed. Missing means null, NaN or ±inf. Thresholds are strict: a feature is dropped when its value is above the threshold.

Modules§

cap 🔒
Step 5: the cap. Greedy column subset selection (Farahat, Ghodsi and Kamel, “An Efficient Greedy Method for Unsupervised Feature Selection”, ICDM 2011) on the candidates’ Spearman correlation matrix: each pick is the candidate that explains the most of all candidates’ spread not yet explained by the ones picked before it. Its gain, in features’ worth (each candidate’s spread is 1, or 0 if it is constant), is the information it adds per dimension. With r rows everything is explained after at most r − 1 picks (centered rows span at most r − 1 directions), so the cap never keeps more.
duplicates 🔒
Step 3: near-duplicates. Spearman correlations between the features (from the rank matrix), then a greedy walk that keeps a feature unless it is too correlated with one kept before it.
matrix 🔒
The rank matrices the correlation and noise steps work on: per feature, the missing values filled with the median, then ranks standardized to mean 0 and variance 1. Ranks make both steps independent of scale and keep a few extreme values from dominating. The correlation step uses average ranks (Spearman); the noise step breaks ties at random instead, so that every pure-noise feature, discrete or not, becomes a uniformly random permutation like the shadow features it is compared with. The cost: within a tie block the order is noise, so a discrete feature keeps only the structure of its blocks. A boolean that splits the rows evenly along their neighborhoods still scores far better than the shadows, but a rare flag (a few percent of ones) keeps little of its signal and is likely dropped as noise.
noise 🔒
Step 4: noise. The Laplacian score (He, Cai and Niyogi, NeurIPS 2005) of each feature on a nearest-neighbor graph of the rows, compared with the scores of shuffled “shadow” features scored in the same graph. A feature that varies no less between neighboring rows than the best shadow carries no neighbor structure: it is noise.
rng 🔒
A small seeded generator whose stream never changes with a dependency update, so a seed gives the same row sample and shadow features in every tsfx version.
shares 🔒
The per-column numbers of the first two steps: the share of missing values and the share of the most frequent value.

Structs§

Cap
Settings of the cap (step 5): keep the most informative features by greedy column subset selection, at most max_features and until min_explained of the candidates’ spread is explained (1.0: until nothing is left to explain), never more than the rows used − 1.
Reduction
Settings of the feature reduction. Each step is turned off with None.
ReductionFit
A fitted reduction: which feature columns to keep and why. Plain data, so it can be kept and applied to other frames with the same columns.

MIN_ROWS 🔒
Fewest rows (groups or windows) any reduction is fitted on.
NOISE_WARN_MIN_FEATURES
With fewer features than this reaching the noise step, the fit warns: the shadow features then make up much of the distance between rows, and the step drops real features by mistake.
NOISE_WARN_MIN_ROWS
With fewer rows than this in the noise step, the fit warns: the neighbor graph is then coarse, and the step drops many real features as noise (in tests, features of medium strength: 45% at 20 rows, 6% at 40, 2% at 60).
