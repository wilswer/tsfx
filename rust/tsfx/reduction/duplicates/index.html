correlation_matrix 🔒
The correlation matrix zᵀ z / n of the columns of z (n rows). With standardized ranks in z (see rank_matrix) this is Spearman’s correlation. Computed in parallel over blocks of 64 columns, each block of rows of the result a single-threaded matrix product, placed by index.
greedy_duplicates 🔒
Walks the features in order and keeps each unless its |correlation| with an already kept feature is above max_correlation; then it is a Duplicate of the kept feature it correlates with most (the one kept first on ties). Indexed by feature; None means kept. order is the priority, a permutation of the feature indices: earlier features win (extraction order in stage 1).
