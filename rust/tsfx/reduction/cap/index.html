Step 5: the cap. Greedy column subset selection (Farahat, Ghodsi and Kamel, “An Efficient Greedy Method for Unsupervised Feature Selection”, ICDM 2011) on the candidates’ Spearman correlation matrix: each pick is the candidate that explains the most of all candidates’ spread not yet explained by the ones picked before it. Its gain, in features’ worth (each candidate’s spread is 1, or 0 if it is constant), is the information it adds per dimension. With r rows everything is explained after at most r − 1 picks (centered rows span at most r − 1 directions), so the cap never keeps more.

The recursive form keeps only the correlation matrix C and the picked vectors ω: for the residual matrix G = C − Σ ω ωᵀ it updates each candidate’s ‖G eᵢ‖² (f) and Gᵢᵢ (g) after every pick, at O(d²) per pick for d candidates, without a second d × d matrix.

Constants§

EXPLAINED_TOLERANCE 🔒
A candidate whose residual variance is at most this is fully explained (each candidate’s own variance is 1, or 0 if it is constant).
GAIN_TIE 🔒
Gains within this relative distance of the best are equal, and the earliest candidate wins. Rounding alone separates gains that are equal by construction, such as the last pick at the rows limit (one direction is left, and every remaining candidate explains all of it).
NEAR_TOP 🔒
When two or more candidates’ gains, give or take their error bounds, can come within this relative distance of the best, those too uncertain (see UNCERTAIN) are recomputed exactly before the choice, so a tie at GAIN_TIE can be told. With a clear best there is no tie to tell.
OMEGA_BLOCK 🔒
Entries per parallel block in subtract_combination.
UNCERTAIN 🔒
The running score f changes by subtraction at every pick, and each update adds rounding error of about ε times the size of its terms; each candidate’s error bound sums those (times a safety factor of 4). Where the bound exceeds this share of GAIN_TIE relative to f, the score is recomputed exactly when it may decide a tie or is reported as a dropped candidate’s next gain. A pick’s gain is always computed exactly.

Functions§

greedy_subset 🔒
Picks candidates greedily, the highest gain first (the first in column order on ties, gains within a relative GAIN_TIE counting as equal), until cap.max_features are picked, the explained share reaches cap.min_explained (checked only below 1.0), or every candidate left is fully explained. c: the candidates’ correlation matrix (d × d, symmetric, diagonal 1, or 0 for a constant candidate). The products with c run in parallel over its rows, each a sequential dot product, so the result does not depend on the thread count.
residual_column 🔒
Gᵢ: candidate i’s column of the residual matrix G = C − Σ ω ωᵀ, exactly, from C and the picked ω (O(d · picks)). ‖Gᵢ‖² is its running score f.
subtract_combination 🔒
target −= Σᵣ coefs[r] · omegas[r], in parallel over blocks of entries; each entry takes its terms in pick order as target + (−c) · x, bit for bit what a sequential scaled_add(−coefs[r], &omegas[r]) per r gives, so the result does not depend on the thread count.
