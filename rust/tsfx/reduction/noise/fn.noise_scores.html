pub(crate) fn noise_scores(

    n_shadows: usize,
    neighbors: usize,

) -> NoiseResult
Expand description

Scores the columns of the rank matrix z against n_shadows shadow columns, each a permutation (from rng, in shadow order) of the standardized ranks of a tie-free column, which is what any noise column becomes after the rank transform. The graph is built on the real and the shadow columns together, with neighbors neighbors per row, so that a pure-noise feature and the shadows are interchangeable: it beats them all with probability 1 / (shadows + 1).
